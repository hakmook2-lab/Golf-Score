[골프 스코어 v3 (한국어 · 日本語) - 배포 · 설치 · 업데이트 방법]

■ 1. GitHub Pages에 올리기 (무료, 최초 1회, PC에서 10분)
  1) github.com 로그인 → 오른쪽 위 [+] → New repository
     - Repository name: golf  (짧을수록 주소가 짧아짐)
     - Public 선택 (무료 Pages는 공개 저장소만 가능. 코드만 공개되고 기록은 각자 폰에만 저장됨)
     - [Create repository]
  2) 만들어진 화면에서 "uploading an existing file" 링크 클릭
  3) 압축을 푼 golf-app 폴더 안의 파일 전부(Ctrl+A)를 끌어다 놓기
     (하위 폴더 없음. 파일만 선택해서 올리면 됨)
  4) 아래 [Commit changes]
  5) 저장소 위 메뉴 Settings → 왼쪽 Pages
     - Source: Deploy from a branch
     - Branch: main / (root) → [Save]
  6) 1~2분 뒤 같은 화면 위쪽에 주소 표시: https://아이디.github.io/golf/
     → 이 주소를 폰에서 열고 설치, 일본 친구들에게도 이 주소를 전달

■ 2. 업데이트할 때
  - 같은 저장소에서 [Add file] → [Upload files] → 바뀐 파일을 끌어다 놓고 [Commit changes]
    (같은 이름 파일은 자동으로 덮어씀)
  - 파일을 고쳤다면 sw.js 맨 위 VERSION 값을 올려야 폰에 [업데이트] 버튼이 뜹니다.
  - 1~2분 뒤 반영. 주소는 바꾸지 마세요(주소별로 기록이 저장됨).

■ 3. 예전 Netlify 앱 기록 옮기기
  - 예전 앱(홈 화면 아이콘)을 열고 기록 탭 → [📤 백업 파일 보내기] 또는 [💾 백업 파일 저장]
  - 새 GitHub 주소 앱 → 기록 탭 → [📂 백업 파일에서 복원]
  - 예전 사이트가 멈춰도, 홈 화면에 설치된 앱은 저장된 파일로 열리는 경우가 많습니다.

■ 4. 언어
  - 폰 언어가 일본어면 자동으로 일본어, 한국어면 한국어로 열립니다.
  - 그 밖의 언어면 처음 한 번 선택 화면이 나옵니다.
  - 언제든 화면 위 [日本語]/[한국어] 버튼 또는 ⚙️ 설정 → 언어 / 言語 에서 변경.

■ 5. 폰에 설치
  - 아이폰: Safari로 주소 열기 → [📲 앱 설치] → 안내대로 공유 → "홈 화면에 추가"
  - 안드로이드: Chrome으로 주소 열기 → [📲 앱 설치] → "설치"
  - 카톡/LINE으로 받은 링크: 앱 안 브라우저에서는 설치가 안 되므로 Safari/Chrome으로 열기

■ 6. 기록 보관
  - 기록은 각자 폰 안에만 저장됩니다(서버 없음, 개인정보 외부 전송 없음).
  - 기록 탭 → [📤 백업 파일 보내기]로 보관하세요.
